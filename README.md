## 🛠️ How to Compile and Run

Make sure a C compiler such as GCC is installed on your system.

### Compile

Navigate to the directory containing the program and run:

```bash
gcc Question-01.c -o Question-01
```

### Run on Windows

```bash
Question-01.exe
```

### Run on Linux/macOS

```bash
./Question-01
```

Replace `Question-01.c` with the name of the program you want to compile.
